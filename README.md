# Deep Space Strategy

Deep Space Strategy studies where humanity should build in the solar system, and in which order. It is a primer for
settling the solar system, based on evidence.

Site: https://bhanneke.github.io/deep-space-strategy/

## Two repositories

| Repository | What it holds |
| --- | --- |
| `bhanneke/deep-space-strategy` (this one) | The strategy work: the landing page and, as they appear, the primer, the strategy studies and the papers |
| [`bhanneke/solmaps`](https://github.com/bhanneke/solmaps) | The open map and route engine: transfer computations, data, tests and every map (resource atlas, 3D atlas, growth map, station siting), at https://bhanneke.github.io/solmaps/ |

The maps moved to solmaps on 2026-10-31; old addresses on this site forward there.

## Build

`python3 site/build_site.py` writes the site into `docs/` for GitHub Pages.
